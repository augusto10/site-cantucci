# Site demonstrativo — Cantucci Osteria

## Como abrir
Na pasta raiz `site-cantucci-df`, execute `npm install` na primeira vez e depois `npm run dev`.
Abra no navegador o endereço exibido pelo terminal. No PowerShell, caso a execução de scripts esteja bloqueada, use `npm.cmd install` e `npm.cmd run dev`.

Também é possível abrir o arquivo `index.html` diretamente no navegador.

## Como publicar
O projeto é estático e pode ser publicado gratuitamente no Vercel, Netlify ou GitHub Pages.

## Arquivos
- `index.html`: estrutura e conteúdo
- `styles.css`: identidade visual responsiva
- `script.js`: menu mobile, animações e categorias do cardápio

## Antes de publicar oficialmente
1. Substitua a marca tipográfica pela logomarca oficial em SVG/PNG.
2. Confirme as unidades, endereços, telefones e horários.
3. Confirme o link oficial do cardápio de cada unidade.
4. Troque as fotografias demonstrativas pelas fotos autorizadas do restaurante.
5. Remova o texto “Site demonstrativo” do rodapé.
6. Adicione Política de Privacidade e banner de cookies, caso sejam usados Analytics, Meta Pixel ou formulários.
